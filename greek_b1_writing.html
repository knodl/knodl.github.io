— I —

Universal Fillers

Each filler is roughly 70 words and slots naturally into all four text types. Memorise one well; have a second as backup. The grammar covers the four core tenses graders look for: ενεστώτας, αόριστος, παρατατικός, μέλλοντας.

Filler · A

Η μετακόμιση & η νέα γειτονιά

Moving + new neighbourhood — the most flexible option, especially strong for complaints (noise) and ads (renting old place).

Πριν από λίγους μήνες μετακόμισα σε ένα καινούριο διαμέρισμα στο κέντρο της πόλης, επειδή ήθελα να είμαι πιο κοντά στη δουλειά μου. Στην αρχή ήταν λίγο δύσκολα, αλλά σιγά σιγά συνήθισα. Η γειτονιά είναι ήσυχη, υπάρχουν πολλά μαγαζιά κοντά και οι γείτονες είναι αρκετά φιλικοί. Το μόνο πρόβλημα είναι ότι κάποιες φορές υπάρχει πολύς θόρυβος τα βράδια και δεν μπορώ να κοιμηθώ καλά. Παρ' όλα αυτά, είμαι αρκετά ευχαριστημένος/-η με τη νέα μου ζωή εδώ.

FriendlyFormalAdComplaint

Friendly → "let me tell you about the move"

Formal → "I recently moved, so I need to update / request..."

Ad → "I moved, so I'm renting/selling my old apartment"

Complaint → "the noise at night is the problem"

Filler · B

Τα μαθήματα ελληνικών

Greek lessons — universally applicable; works as a personal note in any letter type.

Εδώ και έναν χρόνο μαθαίνω ελληνικά, γιατί μου αρέσει πολύ η Ελλάδα και θέλω να ζήσω εκεί στο μέλλον. Στην αρχή ήταν πολύ δύσκολα, ειδικά η γραμματική και τα ρήματα. Όμως, με τη βοήθεια του δασκάλου μου και με αρκετή υπομονή, βλέπω ότι κάνω πρόοδο. Διαβάζω καθημερινά, ακούω ελληνική μουσική και προσπαθώ να μιλάω με φίλους από την Ελλάδα. Σύντομα θα δώσω εξετάσεις για το πιστοποιητικό ελληνομάθειας και ελπίζω να τα καταφέρω.
≈ 75 λέξεις
FriendlyFormalSchool topics

Friendly → "guess what, I've started learning Greek"

Formal → "I'm learning Greek, that's why I'm requesting course info / scholarship / certificate"

Ad → adapt: "I'm a Greek learner offering language exchange"

Complaint → weak fit; prefer Filler A or C here.

Filler · C

Οι διακοπές & το ταξίδι

Holidays + travel — perfect for friendly letters and complaints (hotel/service issues).

Το καλοκαίρι αποφάσισα να πάω διακοπές σε ένα νησί στην Ελλάδα. Έκλεισα ένα ξενοδοχείο κοντά στη θάλασσα και ταξίδεψα με το πλοίο. Στην αρχή όλα ήταν υπέροχα: ο καιρός ήταν καλός, η παραλία ήταν καθαρή και το φαγητό πολύ νόστιμο. Όμως, μετά από λίγες μέρες παρουσιάστηκαν κάποια προβλήματα στο δωμάτιό μου, με αποτέλεσμα να μη μείνω ευχαριστημένος/-η. Παρ' όλα αυτά, γνώρισα νέους ανθρώπους και έμαθα πολλά πράγματα για τον τόπο και την κουλτούρα του.
≈ 75 λέξεις
FriendlyComplaintAd

Friendly → classic "tell me about your holidays" prompt

Complaint → hotel / travel agency / airline complaint — drop in details about the "προβλήματα στο δωμάτιο"

Ad → recommend a place you visited; offer to rent it

Formal → request refund / compensation from agency

— II —

Quick Score Boosters

Easy points the B1 graders specifically reward. Tick each one as you write.

Checklist before submitting

  • Connectors (4–5 per text): όμως, ωστόσο, παρ' όλα αυτά, επειδή, γιατί, για τον λόγο αυτό, επιπλέον, τέλος, στην αρχή, σιγά σιγά, σύντομα
  • Mix four tenses: ενεστώτα + αόριστο + παρατατικό + μέλλοντα — Filler A naturally does this
  • Don't mix register: friendly = εσύ throughout · formal = πληθυντικός ευγενείας (εσείς, σας) throughout
  • Word count: aim 140–160. Below 130 loses marks; above 180 too
  • Punctuation: comma after Αγαπητέ μου / Αξιότιμε κύριε; comma before connectors like "για τον λόγο αυτό"
  • Closing formula matters: Με αγάπη / Φιλικά (informal) · Με εκτίμηση (formal)
  • Use 1–2 idiomatic touches: "ελπίζω να τα καταφέρω", "σιγά σιγά", "παρ' όλα αυτά", "εκ των προτέρων"

Drill Sheet · 10 Sample Prompts

Realistic exam prompts. For each one, decide: which of the 4 templates? which filler? then write a 150-word response in 25–30 minutes (the real exam allows ~27 min per text).

Γράψτε ένα γράμμα σ' έναν φίλο σας που σπουδάζει στο εξωτερικό και πείτε του τα νέα σας από τους τελευταίους μήνες.

Strategy Friendly letter template + Filler A (moving) or Filler B (Greek lessons). Open with Αγαπητέ μου, close with Με αγάπη.
Β1 · A part Informal Friendly letter

Επιστρέψατε από διακοπές σε ένα ελληνικό νησί και είχατε σοβαρά προβλήματα στο ξενοδοχείο. Γράψτε στον διευθυντή για να εκφράσετε τα παράπονά σας και να ζητήσετε αποζημίωση.

Strategy Complaint template + Filler C (holidays). Stay in πληθυντικός ευγενείας. End with concrete request — refund / partial refund / written reply.
Β1 · B part Formal Complaint

Θέλετε να νοικιάσετε το παλιό σας διαμέρισμα. Γράψτε μια αγγελία για την εφημερίδα όπου περιγράφετε το σπίτι, τη γειτονιά και τους όρους ενοικίασης.

Strategy Ad template + Filler A (you moved, so the old flat is free). Open with ΕΝΟΙΚΙΑΖΕΤΑΙ. Include: τετραγωνικά, δωμάτια, τιμή, τηλέφωνο.
Β1 · A part Formal Ad

Γράψτε ένα γράμμα στον διευθυντή ενός σχολείου ξένων γλωσσών στην Ελλάδα και ζητήστε πληροφορίες για ένα καλοκαιρινό μάθημα ελληνικών (τιμή, ημερομηνίες, διαμονή).

Strategy Formal letter template + Filler B (Greek lessons — explains why you want the course). Be specific about what info you need. Πληθυντικός ευγενείας.
Β1 · B part Formal Request info

Ένας Έλληνας φίλος σας σας προσκάλεσε στον γάμο του τον επόμενο μήνα. Γράψτε του για να του πείτε αν θα έρθετε και για να του δώσετε τα νέα σας.

Strategy Friendly letter + Filler A or B. Confirm/decline early in the main paragraph, then segue: "Εν τω μεταξύ, να σου πω και τα δικά μου νέα..." → filler.
Β1 · A part · A2 ✓ Informal Friendly letter

Ένα μπαρ κάτω από το σπίτι σας κάνει πολύ θόρυβο τα βράδια. Γράψτε στον δήμο για να εκφράσετε τα παράπονά σας και να ζητήσετε λύση.

Strategy Complaint template + Filler A — this is the scenario the filler was built for. Direct fit. End with concrete demand: "παρακαλώ να πάρετε μέτρα".
Β1 · B part Formal Complaint

Θέλετε να βρείτε έναν Έλληνα συνομιλητή για να εξασκείτε τα ελληνικά σας. Γράψτε μια ανακοίνωση/αγγελία για τον πίνακα ανακοινώσεων του σχολείου σας.

Strategy Ad template (lighter, more personal tone) + Filler B (Greek lessons — directly explains why). Include level, availability, contact.
Β1 · A part · A2 ✓ Semi-formal Ad

Παραγγείλατε ένα προϊόν από ένα ηλεκτρονικό κατάστημα και ήρθε χαλασμένο και με μεγάλη καθυστέρηση. Γράψτε επίσημη επιστολή παραπόνων.

Strategy Complaint template. This one needs an adapted micro-filler — describe the order timeline using past tenses. Use Filler A only as a brief context line ("μετακόμισα και χρειαζόμουν επειγόντως..."). Demand: refund or replacement.
Β1 · B part Formal Complaint

Γράψτε μια κάρτα σε έναν φίλο σας από τις διακοπές σας και πείτε του πώς περνάτε.

Strategy A2-style. Friendly letter (shortened) + Filler C (holidays). Keep it lighter — for A2 you can drop the filler word count to ~50 and keep total around 80–100 words.
A2 ✓ · B1 light Informal Postcard

Γράψτε στον δήμαρχο της πόλης σας για να ζητήσετε άδεια να οργανώσετε μια εκδήλωση στην πλατεία της γειτονιάς σας.

Strategy Formal letter (request for permission) + Filler A (new neighbourhood — explains why you want to organise something local). State event type, date, expected attendees, why it matters.
